## 1GB到底能不能跑Windows

技术上能装，实际用不了。Windows Server 2022空跑就要占用900MB到1.5GB内存，1GB套餐系统启动完内存就见底，进桌面后任务管理器显示占用97%，开任何业务软件都卡。

按内存分档的经验值：2GB能跑Windows，但只够单个浏览器加一个挂机脚本这类轻量单任务；4GB是舒适线，开浏览器、跑业务软件、挂Python脚本不会互相抢内存；8GB以上用于多人共用远程桌面或跑SQL Server这类重服务。

磁盘同样卡人。Windows系统盘装完通常占20到30GB，套餐给10GB SSD连系统都装不进去。雨云这几档都是30GB系统盘，刚够装系统加少量软件，业务数据多了要单独规划存储。

**2GB够不够？**

Windows镜像比Linux大，通常10到20分钟。超过30分钟还没好，联系客服重置一次。

要改。首次登录后先改默认密码，再把RDP端口从3389换成其他端口，防火墙只放行必要端口，能挡掉大部分扫描爆破。
